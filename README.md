# Health Tracker

แอปบันทึกน้ำหนัก อาหาร และการออกกำลังกายส่วนตัว ใช้งานได้โดยไม่ต้องติดตั้งและเก็บข้อมูลไว้ในเบราว์เซอร์ของอุปกรณ์

**เปิดแอป:** https://porames11.github.io/health-tracker/

## เปิดใช้งาน

เปิด `index.html` หรือเข้าเว็บไซต์ผ่าน GitHub Pages ของ repository นี้

## ข้อมูลและความเป็นส่วนตัว

- ข้อมูลสุขภาพเก็บใน `localStorage` ของเบราว์เซอร์ ไม่ได้ถูกอัปโหลดเข้า GitHub
- มือถือและคอมพิวเตอร์จะมีข้อมูลแยกกันจนกว่าจะเพิ่มระบบซิงก์ในอนาคต
- ควรใช้เมนูตั้งค่าเพื่อส่งออกไฟล์ JSON สำรองเป็นระยะ

## ความสามารถล่าสุด

- ฐานอาหารเริ่มต้นกว่า 130 เมนู และจำเมนูใหม่ที่ผู้ใช้บันทึกเป็น “อาหารของฉัน”
- กราฟแนวโน้มน้ำหนัก 30 รายการล่าสุด
- ประมาณพลังงานที่เผาผลาญจากประเภทกิจกรรม ความหนัก ระยะเวลา และน้ำหนักล่าสุด
- แนบรูปอาหารและเตรียมจุดเชื่อมต่อ AI ผ่านเซิร์ฟเวอร์ที่ปลอดภัย

ค่าพลังงานและสารอาหารเป็นค่าประมาณ ควรตรวจปริมาณจริงก่อนบันทึก โดยเฉพาะอาหารที่มีน้ำมัน น้ำตาล หรือขนาดเสิร์ฟต่างกันมาก

### การวิเคราะห์อาหารจากรูป

หน้าเว็บจะไม่เก็บ API key ของ AI โดยตรง เพราะ GitHub Pages เป็นเว็บสาธารณะ ปุ่มวิเคราะห์จะทำงานเมื่อกำหนด `window.HEALTH_TRACKER_AI_ENDPOINT` ให้ชี้ไปยัง backend ที่รับ `{ image }` และส่งกลับ `{ name, calories, protein, carbs, fat, confidence }` เท่านั้น

## ไฟล์หลัก

- `index.html` — โครงสร้างหน้าจอ
- `style.css` — รูปแบบและหน้าจอมือถือ
- `app.js` — การทำงานและการจัดเก็บข้อมูล
- `food-db.js` — ฐานอาหารเริ่มต้น
